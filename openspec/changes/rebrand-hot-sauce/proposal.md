# Proposal

## Why

The rainbow is the game's only identity, and it doesn't fit (tamsler/wigglefeast#59). It's in the logo's "feast" gradient, the app icon worm and a skin, and it uses the same hues as the food, so nothing reads as *Wigglefeast*. The user reviewed three directions in the Skin Lab and approved **Hot Sauce**: one gradient from pink `#ff2e88` to orange `#ff9f1c`. It's warm, suggests food, and stands out on the navy arena.

## What Changes

- **Logo:** the menu wordmark's "feast" uses the Hot Sauce gradient instead of the rainbow.
- **Buttons:** the primary buttons (Play, Play again, Resume, Back, Play here, and Reload on the update banner) use the Hot Sauce gradient, with matching dark text and a pressed shadow.
- **Icons:** the app icons (192 and 512 px, maskable), the Apple touch icon and the favicon are redrawn as the curled worm in the Hot Sauce gradient on the navy arena. The file names stay the same.
- **Icon script:** the icons are generated by a script in the repo, so they can be regenerated later. The script lives in `tools/`, which the release check treats as not shipped.
- **Unchanged:** the browser theme colour (status bar) stays arena navy.

### Out of scope

- Skins, including hiding Rainbow, which is handled by the skin change (#58).
- Secondary UI accents (the cyan focus ring, range slider, difficulty buttons, BOOST badge). They stay as they are; cyan works as a complement to the brand.
- A new typeface or wordmark shape, a splash screen, or store and social artwork.

## Capabilities

### New Capabilities
- `branding`: the game's visual identity. The brand gradient, where it's used, and the app icon.

## Impact

- `style.css`: brand colour tokens; the wordmark and primary button styles.
- `icons/*.png`: regenerated, with the same names and sizes.
- `tools/make-icons.js` (new, not shipped): draws the icons in headless Chrome using the test helper and writes the PNGs.
- `.github/scripts/check-version.sh`: `tools/` joins the paths that don't need a release bump.
- `README.md`: how to regenerate the icons.
- `tests/`: style checks for the brand colours, icon dimensions, and the release-check exemption.
- `sw.js`: `VERSION` bump. `FILES` is unchanged.
- **Installed copies:** Chrome and Android refresh the icon when the update installs. iOS keeps the old home-screen icon until the app is removed and added again, which is a platform limit.
